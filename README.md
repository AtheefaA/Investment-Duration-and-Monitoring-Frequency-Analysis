# 📊 Investment Duration and Monitoring Frequency Analysis

## 📌 Project Overview

The **Investment Duration and Monitoring Frequency Analysis** project is a Power BI dashboard designed to analyze investment patterns based on duration and monitoring frequency. It provides interactive visualizations and insights that help understand investor behavior, investment preferences, and monitoring habits through data-driven analysis.

---

## 🎯 Objectives

* Analyze investment duration patterns.
* Examine monitoring frequency among investors.
* Visualize investment trends using interactive dashboards.
* Identify key insights from financial data.
* Support informed decision-making through data analysis.
